# AlgoViz — Algorithm Visualizer

Visualisasi algoritma interaktif untuk mahasiswa Informatika. Dibuat dengan HTML, CSS, dan JavaScript murni — tidak perlu instalasi apapun.

## 🚀 Demo

Buka langsung di browser: [moonzyr17.github.io/IF3123](https://moonzyr17.github.io/IF3123)

## ✨ Fitur

### 📊 Sorting Algorithms
- **Bubble Sort** — O(n²)
- **Selection Sort** — O(n²)
- **Insertion Sort** — O(n²)
- **Merge Sort** — O(n log n)
- **Quick Sort** — O(n log n)

Fitur: animasi step-by-step, kontrol kecepatan, ukuran array, counter perbandingan & swap, info kompleksitas.

### 🗺️ Pathfinding Algorithms
- **BFS** (Breadth-First Search) — jalur terpendek
- **DFS** (Depth-First Search) — eksplorasi mendalam
- **Dijkstra** — weighted shortest path

Fitur: grid interaktif 20×35, gambar dinding sendiri, pindah titik start/end, generate maze acak, animasi frontier.

### 🌳 Tree Traversal
- **Inorder** (Left → Root → Right)
- **Preorder** (Root → Left → Right)
- **Postorder** (Left → Right → Root)
- **Level Order** (BFS)

Fitur: Binary Search Tree interaktif, insert node sendiri, visualisasi SVG, highlight traversal path, hasil traversal animasi.

## 🛠️ Cara Pakai

Tidak perlu instalasi. Cukup clone dan buka di browser:

```bash
git clone https://github.com/moonzyr17/IF3123.git
cd IF3123
# Buka index.html di browser
```

Atau langsung buka file `index.html` di browser favorit kamu.
